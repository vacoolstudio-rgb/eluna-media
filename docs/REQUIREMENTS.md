# Eluna Media — Требования (v1.0)

Дата: 2026-07-12. Основано на анализе ~12 конкурентов (Google Play / App Store),
тем жалоб из отзывов, и паттернов приложений семейства Eluna (Reader, Cycle).

## 1. Позиционирование

Полностью приватный офлайн-конвертер фото/видео/аудио для Android и iOS.
Один экран — результат («сжать», «уложиться в размер», «в MP4», «вытащить звук»),
вся мощность FFmpeg — на один тап глубже. Бесплатно и без монетизации.

**Формула из исследования:** UX уровня Panda (4.67★) + мощность уровня
Media Converter (3.4★ из-за UX) + приватность уровня Kompresso + честность YouCut.

## 2. Непреложные принципы (нарушать нельзя)

| # | Принцип |
|---|---------|
| P1 | Без подписок, без пейволов на функции, без вотермарок. Батч бесплатен навсегда. |
| P2 | **Монетизации нет вообще**: ни рекламы, ни покупок внутри, ни донатов. Решение владельца от 2026-08-05, заменяет прежние P2–P4 (один NPA-баннер + разовое «убрать рекламу»). |
| P3 | **Сети нет вообще.** Release-сборка не имеет разрешения INTERNET, и `android/app/src/release/AndroidManifest.xml` вырезает его через `tools:node="remove"`, чтобы зависимость не вернула его незаметно. |
| P4 | Без бэкенда, регистрации, аналитики, crash-SDK, проверки обновлений. |
| P5 | Только бесплатные open-source библиотеки; никаких закрытых бинарников в процессе (это же снимает конфликт GPL — см. NOTICE.md). |

## 4. Функциональные требования

### 4.1 Конвертация (ядро — есть, расширить)
- FR-1. Видео: MP4/MKV/MOV/WebM/AVI; H.264/H.265/VP9/MPEG-4/remux. (есть)
- FR-2. Аудио: MP3/M4A/WAV/FLAC/OGG/Opus, извлечение из видео. (есть)
- FR-3. Изображения: JPEG/PNG/WebP/BMP/TIFF/GIF. (есть)
- FR-4. **Целевой размер файла**: пользователь задаёт МБ; битрейт = размер×8×0.93/длительность − аудио-битрейт, с maxrate/bufsize; предупреждение при недостижимом target.
- FR-5. **Оценка размера результата** до старта (для битрейт/target-режимов — точная, для CRF — не показывается).
- FR-6. Трансформации: поворот, зеркало, скорость 0.5–2×.
- FR-7. Субтитры: сохранять при конверсии в MP4/MKV (опция).
- FR-8. Trim: начало/конец для одиночного файла.
- FR-9. Retry упавшего задания в один тап.
- FR-10. Сохранение результата в галерею (фото/видео) или системную папку; Share. Аудио — Share/копия в папку загрузок.

### 4.2 UX-режимы
- FR-11. **Simple (по умолчанию)**: карточки-пресеты: «Сжать видео», «Уложиться в размер», «Совместимый MP4», «Извлечь звук (MP3)», «GIF из видео», «Сжать фото», «WebP из фото». Выбор файлов → пресет → Convert.
- FR-12. **Advanced**: все текущие контролы + новые (FR-4..FR-8). Переключатель Simple/Advanced запоминается.
- FR-13. Файлы, добавленные в любом режиме, показываются списком с именем, размером, длительностью.
- FR-26. **Переименование результата** до старта: имя без расширения (расширение задаёт формат), пустое поле возвращает имя источника. Только для задания в очереди — после конверсии файл уже существует и, при автосохранении, уже скопирован в галерею под старым именем.
- FR-27. **Удаление оригиналов** (сценарий «сжать, чтобы освободить место»). Кнопка на вкладке «Завершённые» + тумблер автоматического запроса после батча (по умолчанию ВЫКЛ). Удаляет только ОС: `MediaStore.createDeleteRequest` (Android) / `PHPhotoLibrary` (iOS) — приложение само ничего не отвязывает, пользователь всегда видит и подтверждает список. Предлагается только для завершённых заданий, результат которых уже сохранён за пределы песочницы; склейки исключены. Суммарный счётчик освобождённого места — в разделе «Хранилище».

### 4.3 Монетизация
- FR-14. Её нет. Ни рекламы, ни покупок, ни донатов, ни «про-версии». Отменяет прежние FR-14/FR-15 (баннер AdMob и разовое «убрать рекламу»), реализованные в v0.1–v0.4 и удалённые 2026-08-05.
- FR-15. Приложение должно быть проверяемо офлайновым: release-сборка без разрешения INTERNET, экран «Сеть и приватность» говорит именно это, и утверждение подтверждается системным списком разрешений.

### 4.4 Доверие и polish
- FR-16. Privacy-intro при первом запуске (3 обещания: офлайн-конверсия, ноль телеметрии, метаданные под контролем) — один экран, кнопка «Понятно».
- FR-17. Экран «Сеть и приватность» в настройках: полный аудит — сетевых каналов нет ни одного, разрешения INTERNET нет, конверсия работает и в авиарежиме.
- FR-18. Rate-us: день 7 и 14 от первого запуска, при ≥2 успешных конверсиях, не чаще 1/день, iOS — всегда нативный промпт, Android — 5★ → Play, <5★ → email.
- FR-19. Хаптика на старт/успех/ошибку конверсии (отключаемая).
- FR-20. Глобальный обработчик ошибок: дружелюбный экран вместо краша, без отправки куда-либо.
- FR-21. Undo-снекбары для удаления заданий/очистки очереди.
- FR-22. Настройки: Внешний вид (тема/OLED/язык) · Конвертация (режим, энергорежим) · Приватность (метаданные, аудит сети) · Хранилище · Поддержка (достижения, оценить, поделиться, лицензии, версия).
- FR-23. Локализация: EN + RU полностью; каркас готов к расширению (ARB).

### 4.5 Платформы
- FR-24. Android 7+ (minSdk 24), iOS 14+. Телефоны и планшеты (NavigationRail ≥720dp — есть), проверка на 320dp и 1.5× шрифте (есть в тестах — сохранить).
- FR-25. Приём файлов из других приложений (Share/Open with) — Android intent-filters + iOS.

## 5. Нефункциональные требования

- NFR-1. **Энергия**: очередь строго последовательная; энергорежим меняет пресет x264/x265 (Эконом=ultrafast, Баланс=veryfast, Качество=medium); при <20% заряда без зарядки — предупреждающий диалог перед стартом.
- NFR-2. **Производительность UI**: без jank — редкие ребилды (Riverpod select уже используется), троттлинг прогресса (есть), const-виджеты.
- NFR-3. **Надёжность**: очередь переживает смерть процесса (есть), частичные файлы удаляются (есть), один упавший файл не роняет батч (есть).
- NFR-4. **Приватность**: сетевого использования нет вовсе; конверсия не требует сети; никакие файлы/метрики не покидают устройство.
- NFR-5. Все host-тесты проходят; новые модули (аргументы FFmpeg, расчёт target-битрейта, майлстоуны rate-us) покрыты unit-тестами.
- NFR-6. Лицензия приложения остаётся GPL v3 (full-gpl FFmpeg) — все новые зависимости совместимы и бесплатны.
